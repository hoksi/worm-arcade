선충은 어떻게 움직이나요?

선충마다 진짜 꼬마선충의 신경 연결 지도(커넥톰, 뉴런과 근육 448개)를 그대로 쓰고, 꼬마선충 오락실에서 진화한 값을 넣었어요. 선충이 느끼는 것은 먹이 냄새, 포식자(당신)의 방향, 포탄의 촉감, 벽의 촉감뿐이에요. 선충들은 바깥 테두리만 있는 곳에서 진화해서, 안쪽 벽은 처음 만나요. 벽도 테두리와 똑같이 코와 몸 옆의 촉감으로 느끼게 했어요. 길이나 정답을 알려 주는 규칙은 없어요. 색깔마다 다른 환경에서 진화해서 도망치는 방식이 달라요. 반격이 켜져 있으면 선충이 진화하며 익힌 대로 정면의 포식자에게 포탄을 뱉어요.
